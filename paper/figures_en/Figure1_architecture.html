Figure 1. Overall architecture of the system. Devices at the four aid stations share a single cloud database (Firebase Realtime Database). Access from every device is controlled in three layers: (i) user authentication, (ii) verification against a pre-registered allow-list, and (iii) privilege and sign-in-method checks. The database is organised by purpose (rooms/, current occupancy; discharged/, discharge records; archives/, records of closed days), and every write operation is logged automatically to auditLog/. All three checks are enforced server-side by the database security rules, not by the user interface. Setting: a two-day outdoor music festival with approximately 50,000 cumulative attendees and four aid stations. The system runs in a standard web browser and requires neither a dedicated application nor an on-site server.
